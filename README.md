## How I work

Agents write the code. I direct them, and I've engineered the system around them, using prompt engineering, context engineering and systems design:

- **Context:** persistent instructions and scoped context for every project, so each agent starts with the rules and only what it needs
- **Skills and routing:** specialist agents and skills picked by task
- **Enforcement:** hooks and guards apply the rules mechanically, covering file placement, branches and secrets
- **Traceability:** a ledger, a branch per task, a repository registry and independent review agents

The discipline I care most about is keeping the output clean: deslopped, decluttered and in the right place. Coding is a craft, and agent-written code should meet that standard.

I started with beginner AI app builders, then moved to Claude chat, then the Claude API and Workbench, where I built my own orchestration pipelines, then Claude Code.

## Before AI

I started TNAADO in 2020 and ran ecommerce businesses: sourcing, warehousing, logistics and distribution. At hundreds of orders a day the repetitive work had to be automated, and AI tools did not exist yet, so I automated it with scripts and systems:

- Scripts that drove the keyboard and mouse and moved data between tools
- Automated dropshipping systems for orders, shipping and logistics
- Inventory and warehouse automation that tracked ownership, cost and sales across every stage of an item's movement
- A platform that reconciled commissions, insurance claims, logistics costs and consigned inventory across dozens of seller accounts, since shut down

Building tools for my own problems became the work.
